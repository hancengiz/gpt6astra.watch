Let your agent watch the sky for you.

No accounts, no apps. Hand the skill file to any coding agent — Claude Code, Codex, Cursor, whatever reads instructions — and it installs a scheduled watcher on your machine that pings you the moment GPT-6 Astra lands.

step 1

Copy the prompt

Paste it into your agent chat.

Install the astra-watch skill from https://gpt6astra.watch/SKILL.md
and set up a scheduled watcher that notifies me when GPT-6 Astra
becomes available on my account. Ask me for my country, and ask me
before reporting anything to the public map.
step 2

Or fetch the skill directly

The agent can pull it itself — the file is plain agent-readable markdown.

curl -fsSL https://gpt6astra.watch/SKILL.md
what happens

Your agent will

Check the live status of your country · pick the best watcher for your setup (Codex account ground-truth if you have the CLI, otherwise the crowd-status watcher) · schedule it every 10 minutes — systemd on Linux, launchd on macOS, Task Scheduler on Windows · fire a desktop notification when Astra lands.

privacy

What leaves your machine

Your two-letter country code, if you say yes to report-back. That's it — no identifiers, no accounts. The map stores country + timestamp + a salted one-way IP hash. Everything is open source: github.com/hancengiz/gpt6astra.watch
